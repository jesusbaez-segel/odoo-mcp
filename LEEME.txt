MCP de Odoo para Claude - Instalacion
=====================================

Que necesitas tener instalado antes:
  - Claude Code o Claude Desktop  (claude.com)
  Y nada mas. No hace falta Docker, ni Python, ni Node.

Pasos:
  1. Descomprime este ZIP en una carpeta (por ejemplo Documentos\odoo-mcp).
  2. Doble clic en  instalar.bat
  3. Responde lo que te pregunta:
       - URL de tu Odoo   (ej.: https://odoo.segel.com.py)
       - Tu email de inicio de sesion en Odoo
       - Tu contrasena de Odoo (no se muestra al escribir)
     El asistente verifica el acceso, guarda la configuracion en tu maquina
     y lo registra en Claude Code y en Claude Desktop automaticamente.
  4. Si usas Claude Desktop, cierralo del todo (icono junto al reloj) y
     vuelve a abrirlo. Luego pide:  "muestrame mis proyectos de Odoo"

Que puedes pedirle a Claude despues:
  - "muestrame el tablero del proyecto X"
  - "crea una tarea ... y asignasela a ..."
  - "mueve la tarea N a En curso"
  - "comenta en la tarea N que ..."
  y cualquier otra cosa de Odoo (clientes, ventas, facturas...).

Si algo no funciona:
  Abre una ventana de comandos y ejecuta esta linea; te dira el error exacto:
     %LOCALAPPDATA%\Programs\odoo-mcp\odoo-mcp.exe --check

Para quitarlo:
  Doble clic en  desinstalar.bat

Tu contrasena queda guardada SOLO en tu maquina, en:
  %APPDATA%\odoo-mcp\config.env
No compartas ese archivo con nadie.
